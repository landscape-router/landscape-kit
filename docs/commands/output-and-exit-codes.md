# 输出与退出码

输出顺序：

1. 安装根目录和当前状态；
2. 未完成事务处理；
3. 部署前检查；
4. 仓库和目标版本；
5. 下载与校验；
6. `.lkb` 备份；
7. 激活与健康检查；
8. 成功结果或回滚结果；
9. 后续人工提醒。

不得输出：

- 管理员密码；
- 初始化配置内容；
- API token；
- 证书私钥；
- 带 query 或 fragment 的预签名 URL。

退出码：

- `0`：目标状态达到；只有 warning 且安装成功时仍返回 `0`；
- `1`：普通失败，当前已提交安装状态未被破坏，包括用户拒绝、安装锁冲突、首次安装失败和 `--force` 提示手工清理；
- `2`：CLI 参数或参数组合错误，沿用 Clap 的用法错误退出码；
- `5`：目标版本激活或后端 repair 失败，但旧版本自动回滚成功；
- `6`：回滚失败、事务或状态损坏，或者需要人工恢复。

除上述值外，v1 不定义其他 `lkit` 管理命令退出码。生产 systemd 环境中的前端保持连接
时，返回 worker 记录的业务命令退出码；SSH 或终端断开时，调用方可能收不到退出状态，
但 systemd worker 继续完成提交或自动回滚。worker 或主机重启导致事务中断时，不伪造
本次退出码；下一次执行先按中断恢复规则处理。

## 首版非目标

- 不自动卸载 NetworkManager。
- 不自动停止、禁用或 mask `systemd-resolved`。
- 不自动修改 `/etc/network/interfaces` 或选择 WAN/LAN 网卡。
- 不自动修改防火墙、SELinux、sysctl、Cgroup 或内核配置。
- 不自动安装系统软件包、PPP 或容器运行时。
- 不自动迁移 `/root/.landscape-router` 等旧手工部署。
- 不支持非 Debian 发行版。
- 不支持 `x86_64` 和 `aarch64` 以外架构。
- 不允许安装 prerelease。
- 不实现 AWS S3 profile、region 或 access key 鉴权。
- 不自动删除旧版本、事务或 `.lkb`。
- 不实现 `.lkb` full scope。
- 不备份数据库、API token、日志和指标历史。
- 不支持自定义端口。
- 不自动清理安装目录；v1 的 `--force` 只提示用户手工处理。
