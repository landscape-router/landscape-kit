# `lkit uninstall`

`uninstall` 卸载已有有效状态的 Landscape 安装。CLI 完成确认后提交结构化操作，
daemon 使用安装记录对应的 systemd、OpenRC 或 SysVinit 后端停止、禁用并注销服务，
创建保护备份并删除受管文件。lkit CLI、daemon、监管进程与宿主网络服务不属于卸载范围。

```text
lkit uninstall [--yes] [--allow-no-backup] [--keep-data]
```

安装根从 lkit 地盘的安装状态发现，不接受 `--install-dir`。交互模式确认卸载计划、
数据损失及网络接管警告；非交互模式必须提供 `--yes`。拒绝确认返回 `1`，缺少必需
确认返回 `2`，均不创建操作、事务或保护备份。控制台卸载菜单未启用。

请求绑定确认时的安装根、版本、完整状态摘要、`allow_no_backup` 与 `keep_data`。
daemon 持锁后复核；现场变化时拒绝，要求重新确认。daemon 不可用或不支持卸载协议时
报错，不在前台执行卸载。

## 清理选项

默认删除安装根的 `current`、`releases/`、`service/`、`data/` 及 lkit 地盘的安装状态。
`--keep-data` 保留整个 `data/`，包括数据库和初始化文件；该选择写入事务，中断恢复也
必须保留。保留的 data 不再属于已安装实例，重新安装仍按首次安装处理。

lkit 地盘的 `config.toml`、`backups/`、`run/` 与安装锁保留。本根历史事务和日志可在
卸载完成后清理；本次卸载的已提交事务与日志保留作为操作结果和崩溃恢复依据，其他根
的历史不受影响。不支持删除整个 lkit 地盘。

## 卸载前检查

前端只读解析安装状态并完成确认。daemon 持全局安装锁后检查安装身份、服务后端及
注册所有权，默认创建当前实例的保护 `.lkb`；失败时保持当前服务与内容不变。
`--allow-no-backup` 允许保护备份失败后继续，不跳过所有权和状态检查。

检测到宿主网络服务被停止、禁用或屏蔽时，确认提示说明卸载不会恢复宿主网络；需要
用户按主机配置另行恢复网络服务。lkit daemon 持续运行，可单独用 `lkit self remove`
移除。

## 执行与提交

卸载事务记录原服务状态、保护备份、安装状态快照和 `keep_data`：

1. `preparing`：准备保护备份及恢复依据，尚未停止服务。
2. `stopping`：停止服务，禁用并注销属于该安装的服务定义。
3. `activating`：按已确认的清理选项删除剩余受管内容与安装状态。
4. `committed`：持久化完成事实，操作结果返回 `0`；重启只补写结果，不重复备份或卸载。

## 中断恢复

卸载采用前向完成：准备阶段中断时结束为失败，用户可重新提交；进入停止或删除阶段
后，daemon 根据同一事务继续注销和删除，遵守原 `keep_data` 选择。即使安装状态已被
删除，也从未完成事务发现目标根。恢复失败保留未完成阶段与诊断信息，阻止后续修改并
由 daemon 重试，不猜测成功。

## 观察与取消

CLI 输出操作 ID，`lkit operation status <ID>` 查询持久化结果。Ctrl+C 只退出观察，
返回 `130`，daemon 继续执行。显式取消只接受排队操作；领取后的卸载不允许取消。
参数错误返回 `2`，普通执行失败返回 `1`，需要继续恢复时观察者返回 `6`。卸载不回滚，
没有退出码 `5`。
